# 配置自定义语言模型指南

本文档详细说明如何在 VS Code 中配置自定义语言模型（如 Kimi、Claude、GPT 等），使其出现在 "Pick Model" 下拉菜单中。

## 概述

要在 VS Code Chat 中使用自定义语言模型，需要创建一个扩展（Extension）来注册模型提供商。整个过程分为两个主要步骤：

1. **声明提供商**：在 `package.json` 中声明语言模型提供商
2. **实现提供商**：在代码中实现模型提供商的接口

## 前置要求

- 了解 VS Code 扩展开发基础
- 有目标模型的 API 访问权限（API Key 等）
- 了解目标模型的 API 接口文档

## 步骤一：创建扩展项目

### 1.1 初始化扩展

```bash
# 使用 Yeoman 生成器创建扩展
npm install -g yo generator-code
yo code
```

选择 "New Extension (TypeScript)"，填写扩展信息。

### 1.2 项目结构

创建后的项目结构应该类似：

```
my-language-model-extension/
├── package.json          # 扩展配置文件
├── tsconfig.json         # TypeScript 配置
├── src/
│   └── extension.ts      # 扩展主文件
└── README.md
```

## 步骤二：配置 package.json

在 `package.json` 的 `contributes` 部分添加语言模型提供商声明：

```json
{
  "name": "my-language-model-extension",
  "displayName": "My Language Model Extension",
  "version": "0.0.1",
  "engines": {
    "vscode": "^1.85.0"
  },
  "activationEvents": [
    "onLanguageModelChatProvider:my-vendor"
  ],
  "contributes": {
    "languageModelChatProviders": [
      {
        "vendor": "my-vendor",
        "displayName": "My AI Provider",
        "managementCommand": "myExtension.manageModels"
      }
    ]
  },
  "main": "./out/extension.js"
}
```

### 配置项说明

- **`vendor`**：唯一的提供商标识符（如 `kimi`、`claude`、`openai`），不能包含空格
- **`displayName`**：在 "Manage Models" 界面中显示的名称
- **`managementCommand`**（可选）：管理模型的命令 ID，用于在模型选择器中显示设置图标

### 激活事件

`activationEvents` 中的 `onLanguageModelChatProvider:my-vendor` 确保当需要该提供商的模型时，扩展会被激活。

## 步骤三：实现模型提供商

在 `src/extension.ts` 中实现模型提供商：

```typescript
import * as vscode from 'vscode';

export function activate(context: vscode.ExtensionContext) {
    // 注册语言模型提供商
    const provider = vscode.lm.registerLanguageModelChatProvider('my-vendor', {
        // 提供模型信息列表
        async provideLanguageModelChatInformation(options, token) {
            return [
                {
                    id: 'kimi-v1',
                    name: 'Kimi Chat',
                    version: '1.0.0',
                    family: 'kimi',
                    maxInputTokens: 200000,      // 最大输入 token 数
                    maxOutputTokens: 8192,       // 最大输出 token 数
                    
                    // 控制是否在 "Pick Model" 中显示
                    isUserSelectable: true,
                    
                    // 是否为默认模型
                    isDefault: false,
                    
                    // 模型分类（可选）
                    category: {
                        label: 'Kimi Models',
                        order: 1
                    },
                    
                    // 模型能力
                    capabilities: {
                        toolCalling: true,       // 支持工具调用
                        agentMode: true,        // 支持 Agent 模式
                        imageInput: false       // 是否支持图像输入
                    },
                    
                    // 详细信息（可选）
                    detail: 'Kimi 是 Moonshot AI 开发的大语言模型',
                    tooltip: 'Kimi Chat - 支持长文本理解'
                }
            ];
        },
        
        // 处理聊天请求
        async provideLanguageModelChatResponse(model, messages, options, progress, token) {
            // 实现模型请求逻辑
            const response = await callKimiAPI(model, messages, token);
            
            // 返回响应流
            return {
                stream: responseStream,
                result: responsePromise
            };
        },
        
        // 计算 token 数量
        async provideTokenCount(model, text, token) {
            // 实现 token 计数逻辑
            // 可以使用模型的 API 或本地估算
            return estimateTokenCount(text);
        }
    });
    
    context.subscriptions.push(provider);
}
```

## 步骤四：实现 API 调用

### 4.1 调用 Kimi API 示例（基于 GitCode API）

如果你的 Kimi API 是通过 GitCode 提供的 OpenAI 兼容接口，可以使用以下实现：

```typescript
import * as https from 'https';
import * as http from 'http';
import { URL } from 'url';

interface KimiMessage {
    role: 'system' | 'user' | 'assistant';
    content: string;
}

// Kimi API 配置
const KIMI_BASE_URL = 'https://api.gitcode.com/api/v5';
const KIMI_API_KEY = '7hBwcGgKdSiGHS1zMBQm8YHN'; // 建议从配置或密钥存储中读取

async function callKimiAPI(
    model: string,
    messages: vscode.LanguageModelChatMessage[],
    token: vscode.CancellationToken
): Promise<{ stream: AsyncIterable<vscode.LanguageModelTextPart>, result: Promise<void> }> {
    
    // 转换消息格式
    const kimiMessages: KimiMessage[] = messages.map(msg => {
        if (msg instanceof vscode.LanguageModelChatUserMessage) {
            return {
                role: 'user',
                content: msg.content.map(part => {
                    if (part instanceof vscode.LanguageModelTextPart) {
                        return part.text;
                    }
                    return '';
                }).join('')
            };
        } else if (msg instanceof vscode.LanguageModelChatAssistantMessage) {
            return {
                role: 'assistant',
                content: msg.content.map(part => {
                    if (part instanceof vscode.LanguageModelTextPart) {
                        return part.text;
                    }
                    return '';
                }).join('')
            };
        } else if (msg instanceof vscode.LanguageModelChatSystemMessage) {
            return {
                role: 'system',
                content: msg.content.map(part => {
                    if (part instanceof vscode.LanguageModelTextPart) {
                        return part.text;
                    }
                    return '';
                }).join('')
            };
        }
        return { role: 'user', content: '' };
    });
    
    // 获取 API Key（优先从密钥存储，否则使用默认值）
    const apiKey = await getApiKey() || KIMI_API_KEY;
    
    // 构建请求数据（OpenAI 兼容格式）
    const requestData = JSON.stringify({
        model: model,  // 例如 'Kimi-K2'
        messages: kimiMessages,
        stream: true,
        temperature: 0.7
    });
    
    // 创建流式响应
    const stream = new AsyncIterableSource<vscode.LanguageModelTextPart>();
    const resultPromise = makeKimiRequest(apiKey, requestData, stream, token);
    
    return {
        stream: stream.asyncIterable,
        result: resultPromise
    };
}

async function makeKimiRequest(
    apiKey: string,
    data: string,
    stream: AsyncIterableSource<vscode.LanguageModelTextPart>,
    token: vscode.CancellationToken
): Promise<void> {
    return new Promise((resolve, reject) => {
        // 解析 Base URL
        const apiUrl = new URL(KIMI_BASE_URL);
        const path = apiUrl.pathname.endsWith('/') 
            ? apiUrl.pathname + 'chat/completions'
            : apiUrl.pathname + '/chat/completions';
        
        const options = {
            hostname: apiUrl.hostname,
            port: apiUrl.port || (apiUrl.protocol === 'https:' ? 443 : 80),
            path: path,
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${apiKey}`,
                'Content-Length': Buffer.byteLength(data)
            }
        };
        
        const httpModule = apiUrl.protocol === 'https:' ? https : http;
        const req = httpModule.request(options, (res) => {
            // 检查响应状态
            if (res.statusCode !== 200) {
                let errorBody = '';
                res.on('data', (chunk) => {
                    errorBody += chunk.toString();
                });
                res.on('end', () => {
                    stream.reject(new Error(`API 请求失败: ${res.statusCode} - ${errorBody}`));
                    reject(new Error(`API 请求失败: ${res.statusCode}`));
                });
                return;
            }
            
            let buffer = '';
            
            res.on('data', (chunk) => {
                buffer += chunk.toString();
                const lines = buffer.split('\n');
                buffer = lines.pop() || '';
                
                for (const line of lines) {
                    const trimmedLine = line.trim();
                    if (!trimmedLine) continue;
                    
                    if (trimmedLine.startsWith('data: ')) {
                        const jsonStr = trimmedLine.slice(6);
                        if (jsonStr === '[DONE]') {
                            stream.resolve();
                            resolve();
                            return;
                        }
                        try {
                            const json = JSON.parse(jsonStr);
                            const content = json.choices?.[0]?.delta?.content || '';
                            if (content) {
                                // 创建 LanguageModelTextPart
                                const textPart = new vscode.LanguageModelTextPart(content);
                                stream.emitOne(textPart);
                            }
                        } catch (e) {
                            // 忽略解析错误，继续处理下一行
                            console.warn('解析 SSE 数据失败:', e, jsonStr);
                        }
                    }
                }
            });
            
            res.on('end', () => {
                // 处理剩余的 buffer
                if (buffer.trim()) {
                    const trimmedLine = buffer.trim();
                    if (trimmedLine.startsWith('data: ')) {
                        const jsonStr = trimmedLine.slice(6);
                        if (jsonStr !== '[DONE]') {
                            try {
                                const json = JSON.parse(jsonStr);
                                const content = json.choices?.[0]?.delta?.content || '';
                                if (content) {
                                    const textPart = new vscode.LanguageModelTextPart(content);
                                    stream.emitOne(textPart);
                                }
                            } catch (e) {
                                // 忽略错误
                            }
                        }
                    }
                }
                stream.resolve();
                resolve();
            });
            
            res.on('error', (err) => {
                stream.reject(err);
                reject(err);
            });
        });
        
        req.on('error', (err) => {
            stream.reject(err);
            reject(err);
        });
        
        token.onCancellationRequested(() => {
            req.destroy();
            stream.reject(new Error('Cancelled'));
            reject(new Error('Cancelled'));
        });
        
        req.write(data);
        req.end();
    });
}

// 简单的 AsyncIterableSource 实现
class AsyncIterableSource<T> {
    private _promise: Promise<void> | undefined;
    private _resolve: (() => void) | undefined;
    private _reject: ((error: any) => void) | undefined;
    private _items: T[] = [];
    private _done: boolean = false;
    private _error: any = undefined;
    
    asyncIterable: AsyncIterable<T> = {
        [Symbol.asyncIterator]: async function* () {
            while (true) {
                if (this._error) {
                    throw this._error;
                }
                
                if (this._items.length > 0) {
                    yield this._items.shift()!;
                    continue;
                }
                
                if (this._done) {
                    return;
                }
                
                if (!this._promise) {
                    this._promise = new Promise<void>((resolve, reject) => {
                        this._resolve = resolve;
                        this._reject = reject;
                    });
                }
                
                try {
                    await this._promise;
                    this._promise = undefined;
                } catch (e) {
                    this._promise = undefined;
                    throw e;
                }
            }
        }.bind(this)
    };
    
    emitOne(item: T) {
        if (this._done) return;
        this._items.push(item);
        if (this._resolve) {
            this._resolve();
            this._promise = undefined;
            this._resolve = undefined;
            this._reject = undefined;
        }
    }
    
    resolve() {
        if (this._done) return;
        this._done = true;
        if (this._resolve) {
            this._resolve();
            this._promise = undefined;
            this._resolve = undefined;
            this._reject = undefined;
        }
    }
    
    reject(error: any) {
        if (this._done) return;
        this._done = true;
        this._error = error;
        if (this._reject) {
            this._reject(error);
            this._promise = undefined;
            this._resolve = undefined;
            this._reject = undefined;
        }
    }
}
```

### 4.2 API Key 管理

建议使用 VS Code 的 SecretStorage API 来安全存储 API Key：

```typescript
const KIMI_SECRET_KEY = 'kimi.apiKey';

async function getApiKey(): Promise<string | undefined> {
    // 优先从密钥存储中读取
    try {
        const apiKey = await context.secrets.get(KIMI_SECRET_KEY);
        if (apiKey) {
            return apiKey;
        }
    } catch (e) {
        console.warn('读取密钥存储失败:', e);
    }
    
    // 如果密钥存储中没有，尝试从配置中读取
    const config = vscode.workspace.getConfiguration('kimi');
    const apiKey = config.get<string>('apiKey');
    
    if (apiKey) {
        return apiKey;
    }
    
    // 如果都没有，返回 undefined（使用默认值或提示用户）
    return undefined;
}

// 保存 API Key 到密钥存储
async function saveApiKey(apiKey: string): Promise<void> {
    await context.secrets.store(KIMI_SECRET_KEY, apiKey);
}
```

**注意**：在实际使用中，建议将 API Key 存储在密钥存储中，而不是硬编码在代码里。

## 步骤五：Token 计数实现

```typescript
async function estimateTokenCount(text: string | vscode.LanguageModelChatMessage): Promise<number> {
    let content = '';
    
    if (typeof text === 'string') {
        content = text;
    } else {
        // 从消息中提取文本
        content = text.content
            .map(part => {
                if (part instanceof vscode.LanguageModelTextPart) {
                    return part.text;
                }
                return '';
            })
            .join('');
    }
    
    // 简单估算：中文约 1.5 字符 = 1 token，英文约 4 字符 = 1 token
    // 实际应该调用模型的 tokenizer API
    const chineseChars = (content.match(/[\u4e00-\u9fa5]/g) || []).length;
    const englishChars = content.length - chineseChars;
    
    return Math.ceil(chineseChars / 1.5 + englishChars / 4);
}
```

## 常见问题

### Q1: 模型没有出现在 "Pick Model" 中？

**检查项**：
1. 确保 `isUserSelectable: true`
2. 检查扩展是否正确激活
3. 查看 VS Code 开发者工具的控制台错误

### Q2: 如何支持流式响应？

使用 `AsyncIterable` 返回流式数据，参考上面的 `AsyncIterableSource` 实现。
