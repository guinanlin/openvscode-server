# 配置自定义语言模型指南

本文档详细说明如何在 VS Code 中配置自定义语言模型（如 Kimi、Claude、GPT 等），使其出现在 "Pick Model" 下拉菜单中。

## 概述

要在 VS Code Chat 中使用自定义语言模型，需要创建一个扩展（Extension）来注册模型提供商。整个过程分为两个主要步骤：

1. **声明提供商**：在 `package.json` 中声明语言模型提供商
2. **实现提供商**：在代码中实现模型提供商的接口

## 前置要求

- 了解 VS Code 扩展开发基础
- 有目标模型的 API 访问权限（API Key 等）
- 了解目标模型的 API 接口文档

## 步骤一：创建扩展项目

### 1.1 初始化扩展

```bash
# 使用 Yeoman 生成器创建扩展
npm install -g yo generator-code
yo code
```

选择 "New Extension (TypeScript)"，填写扩展信息。

### 1.2 项目结构

创建后的项目结构应该类似：

```
my-language-model-extension/
├── package.json          # 扩展配置文件
├── tsconfig.json         # TypeScript 配置
├── src/
│   └── extension.ts      # 扩展主文件
└── README.md
```

## 步骤二：配置 package.json

在 `package.json` 的 `contributes` 部分添加语言模型提供商声明：

```json
{
  "name": "my-language-model-extension",
  "displayName": "My Language Model Extension",
  "version": "0.0.1",
  "engines": {
    "vscode": "^1.85.0"
  },
  "activationEvents": [
    "onLanguageModelChatProvider:my-vendor"
  ],
  "contributes": {
    "languageModelChatProviders": [
      {
        "vendor": "my-vendor",
        "displayName": "My AI Provider",
        "managementCommand": "myExtension.manageModels"
      }
    ]
  },
  "main": "./out/extension.js"
}
```

### 配置项说明

- **`vendor`**：唯一的提供商标识符（如 `kimi`、`claude`、`openai`），不能包含空格
- **`displayName`**：在 "Manage Models" 界面中显示的名称
- **`managementCommand`**（可选）：管理模型的命令 ID，用于在模型选择器中显示设置图标

### 激活事件

`activationEvents` 中的 `onLanguageModelChatProvider:my-vendor` 确保当需要该提供商的模型时，扩展会被激活。

## 步骤三：实现模型提供商

在 `src/extension.ts` 中实现模型提供商：

```typescript
import * as vscode from 'vscode';

export function activate(context: vscode.ExtensionContext) {
    // 注册语言模型提供商
    const provider = vscode.lm.registerLanguageModelChatProvider('my-vendor', {
        // 提供模型信息列表
        async provideLanguageModelChatInformation(options, token) {
            return [
                {
                    id: 'kimi-v1',
                    name: 'Kimi Chat',
                    version: '1.0.0',
                    family: 'kimi',
                    maxInputTokens: 200000,      // 最大输入 token 数
                    maxOutputTokens: 8192,       // 最大输出 token 数
                    
                    // 控制是否在 "Pick Model" 中显示
                    isUserSelectable: true,
                    
                    // 是否为默认模型
                    isDefault: false,
                    
                    // 模型分类（可选）
                    category: {
                        label: 'Kimi Models',
                        order: 1
                    },
                    
                    // 模型能力
                    capabilities: {
                        toolCalling: true,       // 支持工具调用
                        agentMode: true,        // 支持 Agent 模式
                        imageInput: false       // 是否支持图像输入
                    },
                    
                    // 详细信息（可选）
                    detail: 'Kimi 是 Moonshot AI 开发的大语言模型',
                    tooltip: 'Kimi Chat - 支持长文本理解'
                }
            ];
        },
        
        // 处理聊天请求
        async provideLanguageModelChatResponse(model, messages, options, progress, token) {
            // 实现模型请求逻辑
            const response = await callKimiAPI(model, messages, token);
            
            // 返回响应流
            return {
                stream: responseStream,
                result: responsePromise
            };
        },
        
        // 计算 token 数量
        async provideTokenCount(model, text, token) {
            // 实现 token 计数逻辑
            // 可以使用模型的 API 或本地估算
            return estimateTokenCount(text);
        }
    });
    
    context.subscriptions.push(provider);
}
```

## 步骤四：实现 API 调用

### 4.1 调用 Kimi API 示例

```typescript
import * as https from 'https';
import * as http from 'http';

interface KimiMessage {
    role: 'system' | 'user' | 'assistant';
    content: string;
}

async function callKimiAPI(
    model: string,
    messages: vscode.LanguageModelChatMessage[],
    token: vscode.CancellationToken
): Promise<{ stream: AsyncIterable<string>, result: Promise<void> }> {
    
    // 转换消息格式
    const kimiMessages: KimiMessage[] = messages.map(msg => {
        if (msg instanceof vscode.LanguageModelChatUserMessage) {
            return {
                role: 'user',
                content: msg.content.map(part => {
                    if (part instanceof vscode.LanguageModelTextPart) {
                        return part.text;
                    }
                    return '';
                }).join('')
            };
        } else if (msg instanceof vscode.LanguageModelChatAssistantMessage) {
            return {
                role: 'assistant',
                content: msg.content.map(part => {
                    if (part instanceof vscode.LanguageModelTextPart) {
                        return part.text;
                    }
                    return '';
                }).join('')
            };
        }
        return { role: 'system', content: '' };
    });
    
    // 获取 API Key（从配置或密钥存储）
    const apiKey = await getApiKey();
    
    // 构建请求
    const requestData = JSON.stringify({
        model: model,
        messages: kimiMessages,
        stream: true
    });
    
    // 创建流式响应
    const stream = new AsyncIterableSource<string>();
    const resultPromise = makeKimiRequest(apiKey, requestData, stream, token);
    
    return {
        stream: stream.asyncIterable,
        result: resultPromise
    };
}

async function makeKimiRequest(
    apiKey: string,
    data: string,
    stream: AsyncIterableSource<string>,
    token: vscode.CancellationToken
): Promise<void> {
    return new Promise((resolve, reject) => {
        const options = {
            hostname: 'api.moonshot.cn',
            path: '/v1/chat/completions',
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${apiKey}`,
                'Content-Length': Buffer.byteLength(data)
            }
        };
        
        const req = https.request(options, (res) => {
            let buffer = '';
            
            res.on('data', (chunk) => {
                buffer += chunk.toString();
                const lines = buffer.split('\n');
                buffer = lines.pop() || '';
                
                for (const line of lines) {
                    if (line.startsWith('data: ')) {
                        const jsonStr = line.slice(6);
                        if (jsonStr === '[DONE]') {
                            stream.resolve();
                            resolve();
                            return;
                        }
                        try {
                            const json = JSON.parse(jsonStr);
                            const content = json.choices?.[0]?.delta?.content || '';
                            if (content) {
                                stream.emitOne(content);
                            }
                        } catch (e) {
                            // 忽略解析错误
                        }
                    }
                }
            });
            
            res.on('end', () => {
                stream.resolve();
                resolve();
            });
            
            res.on('error', (err) => {
                stream.reject(err);
                reject(err);
            });
        });
        
        req.on('error', (err) => {
            stream.reject(err);
            reject(err);
        });
        
        token.onCancellationRequested(() => {
            req.destroy();
            stream.reject(new Error('Cancelled'));
            reject(new Error('Cancelled'));
        });
        
        req.write(data);
        req.end();
    });
}

// 简单的 AsyncIterableSource 实现
class AsyncIterableSource<T> {
    private _promise: Promise<T> | undefined;
    private _resolve: ((value: T) => void) | undefined;
    private _reject: ((error: any) => void) | undefined;
    private _items: T[] = [];
    
    asyncIterable: AsyncIterable<T> = {
        [Symbol.asyncIterator]: async function* () {
            while (true) {
                if (this._items.length > 0) {
                    yield this._items.shift()!;
                } else if (this._promise) {
                    try {
                        await this._promise;
                        if (this._items.length === 0) {
                            return;
                        }
                    } catch (e) {
                        throw e;
                    }
                } else {
                    this._promise = new Promise((resolve, reject) => {
                        this._resolve = resolve;
                        this._reject = reject;
                    });
                }
            }
        }.bind(this)
    };
    
    emitOne(item: T) {
        this._items.push(item);
        if (this._resolve) {
            this._resolve(undefined as any);
            this._promise = undefined;
            this._resolve = undefined;
            this._reject = undefined;
        }
    }
    
    resolve() {
        if (this._resolve) {
            this._resolve(undefined as any);
        }
    }
    
    reject(error: any) {
        if (this._reject) {
            this._reject(error);
        }
    }
}
```

### 4.2 API Key 管理

建议使用 VS Code 的 SecretStorage API 来安全存储 API Key：

```typescript
async function getApiKey(): Promise<string> {
    const secretStorage = vscode.workspace.getConfiguration('myExtension');
    let apiKey = secretStorage.get<string>('apiKey');
    
    if (!apiKey) {
        // 提示用户输入 API Key
        apiKey = await vscode.window.showInputBox({
            prompt: '请输入 Kimi API Key',
            password: true,
            ignoreFocusOut: true
        });
        
        if (apiKey) {
            // 保存到密钥存储
            await vscode.commands.executeCommand(
                'setContext',
                'myExtension.apiKey',
                apiKey
            );
        }
    }
    
    if (!apiKey) {
        throw new Error('API Key 未配置');
    }
    
    return apiKey;
}
```

## 步骤五：Token 计数实现

```typescript
async function estimateTokenCount(text: string | vscode.LanguageModelChatMessage): Promise<number> {
    let content = '';
    
    if (typeof text === 'string') {
        content = text;
    } else {
        // 从消息中提取文本
        content = text.content
            .map(part => {
                if (part instanceof vscode.LanguageModelTextPart) {
                    return part.text;
                }
                return '';
            })
            .join('');
    }
    
    // 简单估算：中文约 1.5 字符 = 1 token，英文约 4 字符 = 1 token
    // 实际应该调用模型的 tokenizer API
    const chineseChars = (content.match(/[\u4e00-\u9fa5]/g) || []).length;
    const englishChars = content.length - chineseChars;
    
    return Math.ceil(chineseChars / 1.5 + englishChars / 4);
}
```

## 常见问题

### Q1: 模型没有出现在 "Pick Model" 中？

**检查项**：
1. 确保 `isUserSelectable: true`
2. 检查扩展是否正确激活
3. 查看 VS Code 开发者工具的控制台错误
4. 确认 `vendor` 名称与 `package.json` 中的一致

### Q2: 如何支持流式响应？

使用 `AsyncIterable` 返回流式数据，参考上面的 `AsyncIterableSource` 实现。

### Q3: 如何支持工具调用？

在 `capabilities` 中设置 `toolCalling: true`，并在处理消息时解析工具调用请求。

### Q4: 如何支持图像输入？

设置 `capabilities.imageInput: true`，并在消息处理中解析图像数据。

### Q5: 如何调试扩展？

1. 按 `F5` 启动扩展开发宿主
2. 在新窗口中测试扩展
3. 查看调试控制台的日志输出
