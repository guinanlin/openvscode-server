# 🚀 快速开始指南

**应用地址**: http://localhost:3000
**状态**: ✅ 运行中

## 30 秒快速测试

### 步骤 1: 打开应用
- 打开浏览器：http://localhost:3000
- 等待 UI 加载（5 秒）

### 步骤 2: 打开 Chat 面板
- 按 **Ctrl+Alt+I** （或 Cmd+Shift+I on Mac）
- 或点击左侧活动栏的聊天图标

### 步骤 3: 发送消息
- 输入：`你好`
- 按 **Enter**

### 步骤 4: 查看结果
- **✅ 成功**: 2-5 秒内收到 Kimi 的回复
- **❌ 失败**: 消息卡在 "Working..." 或显示错误

## 🔧 故障排除

### 问题 1: Chat 面板显示错误或无法加载
**解决方案**:
1. F12 → Console
2. 查找红色错误信息
3. 特别查找 "ERR" 或 "Timed out"
4. 参考完整的 `Chat-测试指南.md`

### 问题 2: 消息永远卡在 "Working..."
**解决方案**:
1. F12 → Network 标签
2. 发送消息
3. 查看是否有 POST 请求到 `api.gitcode.com`
4. 检查响应状态码（应该是 200）
5. 如果是 4xx 或 5xx，可能是 API 密钥或服务问题

### 问题 3: 控制台显示 "Timed out waiting for authentication provider"
**解决方案**:
1. 这表示修复可能没有被正确应用
2. 检查 `/extensions/kimi-chat-extension/out/extension.js` 的修改时间戳
3. 确保是最新编译的版本
4. 尝试：F5 刷新页面（清除缓存）
