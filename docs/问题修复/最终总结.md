## 故障排除快速指南

### 如果 Chat 面板不能加载
1. F12 打开控制台
2. 查找 "ERR" 日志
3. 特别查找 "Timed out waiting for authentication" 或 "No default agent"
4. 参考 `/docs/问题修复/Chat-测试指南.md`

### 如果消息卡在 "Working..."
1. 检查 Network 标签中的 API 请求
2. 查看 HTTP 状态码（应该是 200）
3. 测试 API 端点：
   ```bash
   curl -X POST https://api.gitcode.com/api/v5/chat/completions \
     -H "Authorization: Bearer 7hBwcGgKdSiGHS1zMBQm8YHN" \
     -H "Content-Type: application/json" \
     -d '{"model":"Kimi-K2","messages":[{"role":"user","content":"hello"}],"stream":true}'
   ```
