## 🔧 技术细节

### 问题根本原因

**循环依赖**：
```
ChatService 需要 agent 数据
    ↓
但 agent 数据只有在 Kimi 扩展被激活时才会出现
    ↓
而激活扩展需要... agent 数据？（循环！）
```

### 解决方案架构

```
1. ChatService 启动
    ↓
2. 查询 agent 数据
    ├─ 找到？使用它
    └─ 没找到？
        ↓
3. 检查 product.json 中的 defaultChatAgent
    ├─ 有？读取 extensionId
    │   ↓
    │   4. 直接激活该扩展（使用 activateById）
    │   ↓
    │   5. 重新查询 agent 数据
    │   ├─ 找到？使用它（成功！）
    │   └─ 没找到？抛出错误
    │
    └─ 没有？抛出错误
```

### 关键实现

**文件**：`src/vs/workbench/contrib/chat/common/chatServiceImpl.ts`
**方法**：`async activateDefaultAgent(location: ChatAgentLocation)`
**行数**：358-378
